- Lidos todos os READMEs existentes nos subprojetos para extrair informações precisas
- Criado `README.md` na raiz com:
  - Descrição do repositório como laboratório IBM Bob
  - Seção de projetos com foco no Galaxium Travels
  - Quick start com `start.sh` e inicialização manual
  - Tabela de endpoints (Frontend, Backend, Swagger, MCP)
  - Seção dedicada à integração com o Bob via MCP (config + tools disponíveis)

O README foi escrito como vitrine do repositório para o GitHub, posicionando o projeto como demonstração prática do IBM Bob com foco na integração dual-protocol (REST + MCP).
